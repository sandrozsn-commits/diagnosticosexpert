# Eletro Lab

Quero que você atue como um Product Designer Sênior, UX Designer, Especialista em Gamificação, Especialista em Educação Digital, Desenvolvedor Full Stack e Arquiteto de Software.

Sua missão é criar um produto SaaS completo chamado:

Laboratório de Diagnóstico em Comandos Elétricos

O objetivo não é criar um curso.

O objetivo é criar a melhor plataforma do Brasil para ensinar eletricistas, técnicos e engenheiros a diagnosticar falhas em comandos elétricos industriais através de simulações extremamente realistas.

Imagine uma mistura de:

 simulador de voo

 Duolingo

 Kahoot

 jogos investigativos

 treinamento industrial

O aluno aprende resolvendo problemas.

Nunca apenas assistindo aulas.

Objetivo

O aluno deverá aprender exatamente como um eletricista experiente pensa diante de um defeito.

O sistema deve ensinar raciocínio lógico.

Não memorização.

Conceito

O aluno recebe uma ocorrência real.

Exemplo:

Motor não liga.

Contator não atraca.

Motor gira invertido.

Relé dispara.

Temporizador não transfere.

Sensor não atua.

Circuito oscila.

Máquina para depois de alguns segundos.

O aluno precisa descobrir o defeito.

Fluxo do caso

Cada caso deve funcionar como uma investigação.

Até encontrar a falha.

O sistema nunca entrega a resposta imediatamente.

O aluno precisa construir o diagnóstico.

Quero decisões reais

Por exemplo:

Medir tensão.

Verificar selo.

Testar contato NF.

Verificar relé térmico.

Conferir alimentação.

Analisar contato auxiliar.

Testar continuidade.

Substituir componente.

Etc.

Cada decisão altera o caso.
